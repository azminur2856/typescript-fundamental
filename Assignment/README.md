# B8A1 – TypeScript & OOP Problem Solving

## Overview

This repository is a collection of my solutions for the TypeScript & OOP assignment, which cover basic types, optional/default/rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises and object-oriented programming. It also features two blog posts on TypeScript concepts.

All problems have been solved in [`solutions.ts`](./src/solutions.ts) with explicit types for parameters and return values, and no `any`.
